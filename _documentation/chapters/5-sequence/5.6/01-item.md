Koala has a powerful keyboard mode, which lets you play pads chromatically, locked to scales, have fine velocity control or create rhythms with note repeat functionality. 

Tap KEYBOARD button to activate keyboard mode, then tap the pad you want to play in keyboard mode.

Tap on KEYBOARD dropdown arrow to select between the four available modes: GRID, KEYBOARD, NOTE REPEAT and VELOCITY. The same menu has a PITCHBEND option [SAMURAI] that adds a pitch bend control next to the keyboard. The scale and keyboard mode are saved with your song.
