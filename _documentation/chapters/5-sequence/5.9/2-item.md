### Editing automation
Double tap a sequence to open the grid, then tap the AUTOMATION button to show the automation lane. Tap CHOOSE to pick which parameter to view: perform effects, mixer channel volumes, bus effect knobs, or third-party plugin effect parameters. In keyboard mode the list shows the pad's parameters: pitch bend, volume, pan, pitch, tone, attack, release, EQ, Chopper DECAY, Quokka synth parameters and third-party plugin instrument parameters. Opening the automation lane remembers and reopens the last automated parameter.

Three tools edit the lane:
* Pencil: draw the curve freehand.
* STEP: draw stepped values that snap to the grid.
* EDIT: drag existing points around.

The trash button clears the automation of the chosen parameter.
