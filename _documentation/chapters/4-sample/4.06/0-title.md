<h2 id="46-sample-controls-volume-pitch-pan-edit-delete">4.6. Sample Controls: Volume, Pitch, Pan, Edit, Delete<br><span lang="zh-CN">4.6. 采样控制：音量、音高、声像、编辑与删除</span></h2>

Pro tip: tap and hold the EDIT button, then tap all the pads you want to tweak. Changes to the VOL, PITCH, PAN and sample editor controls will be applied to all selected pads.  
<span lang="zh-CN">技巧：按住 EDIT（编辑），再点击所有要调整的打击垫。对 VOL（音量）、PITCH（音高）、PAN（声像）和采样编辑器所做的调整会应用于所有选中的打击垫。</span>

Pro tip: while holding or adjusting a knob or slider (VOL, PITCH, PAN, editor or effect knobs), tap the value readout to type an exact value on the numpad. On desktop, you can also Cmd/Ctrl+click a knob.  
<span lang="zh-CN">技巧：按住或调节旋钮或滑杆时，可点击数值显示，用数字键盘输入精确数值。这个操作适用于音量、音高、声像、编辑器和效果器控件。桌面端也可以按住 Cmd 或 Ctrl 并点击旋钮。</span>
