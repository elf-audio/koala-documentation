<h2 id="21-sample-screen">2.1. Sample Screen<br><span lang="zh-CN">2.1. 采样界面</span></h2>

{% flexible_image link="sample-monitoring-active.png" alt="Sample screen" %}

Sample screen is used to load samples to the pads, manipulate samples and for resampling.  
<span lang="zh-CN">在 SAMPLE（采样）界面，可以将采样载入打击垫、编辑采样和重采样。</span>

When using the mic as input, additional input effects can be applied during the sampling process.  
<span lang="zh-CN">以麦克风为输入时，可以在录制采样的同时应用输入效果。</span>

64 pads are available for samples, divided into banks A,B,C,D.  
<span lang="zh-CN">64 个采样打击垫分为 A、B、C、D 四组。</span>

Use powerful features like looping, stem extraction, time stretching, resampling, EQ per pad and auto-chop.  
<span lang="zh-CN">可用功能包括循环播放、分轨提取、时间拉伸、重采样、单个打击垫均衡和自动切片。</span>

Tap and hold any free pad to start recording from mic input. Release to stop recording.  
<span lang="zh-CN">按住任意空打击垫即可开始通过麦克风录音，松开即停止。</span>

Pro tip: you can route pads to additional output channels when Koala is loaded as an AUv3 plugin on iOS or as a DAW plugin on desktop (not supported on Android).  
<span lang="zh-CN">技巧：在 iOS 上将 Koala 用作 AUv3 插件，或在桌面 DAW 中加载 Koala 插件时，可将打击垫路由到额外的输出通道。Android 不支持此功能。</span>
