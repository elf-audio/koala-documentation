## 13.1. Installing and Updating
Download Koala for macOS, Windows or Linux from <https://koalasampler.com/download/>. Windows needs Windows 10 version 1903 or later. The macOS and Windows installers install the standalone app, the Koala DAW plugin (AU / VST3 on macOS, VST3 on Windows) and Koala FX together in one step. Linux provides a web installer plus CLAP and VST3 builds for x86_64 and arm64 / Raspberry Pi, with native Wayland support.

Koala checks for updates when it starts. When a newer version is available, an UPDATE AVAILABLE panel appears in the MENU with the release notes behind MORE INFO and a DOWNLOAD button that fetches the right installer for your platform.
