* **File**: New Song (Cmd+N), Import Audio File (Cmd+J), Save Song (Cmd+S), Export Selected Samples (Shift+Cmd+R), Export All Samples, Export Current Sequence, Export All Sequences, Export Koala Song (Shift+Cmd+E), Open Song Folder, Take screenshot (Cmd+P).  
  <span lang="zh-CN">**File（文件）**：新建工程（Cmd+N）、导入音频文件（Cmd+J）、保存工程（Cmd+S）、导出所选采样（Shift+Cmd+R）、导出全部采样、导出当前音序、导出全部音序、导出 Koala 工程（Shift+Cmd+E）、打开工程文件夹、截图（Cmd+P）。</span>
* **Edit**: Undo (Cmd+Z), Redo (Shift+Cmd+Z), Label Current Pad (Cmd+L), Sample Info (Cmd+I), Edit Sample (Cmd+E) which opens the wave editor.  
  <span lang="zh-CN">**Edit（编辑）**：撤销（Cmd+Z）、重做（Shift+Cmd+Z）、为当前打击垫加标签（Cmd+L）、采样信息（Cmd+I）、编辑采样（Cmd+E，打开波形编辑器）。</span>
* **Window**: resize the window to common phone and tablet sizes, or flip between Landscape and Portrait (Cmd+9). Koala's layout adapts to the window just like it does to different screens. The standalone app and DAW plugin remember their last window size.  
  <span lang="zh-CN">**Window（窗口）**：将窗口调整为常见手机或平板尺寸，或切换横屏与竖屏布局（Cmd+9）。Koala 会随窗口尺寸调整布局。独立应用和 DAW 插件都会记住上次的窗口尺寸。</span>
* **Help**: Keyboard shortcuts, About Koala.  
  <span lang="zh-CN">**Help（帮助）**：键盘快捷键、关于 Koala。</span>
* **Koala**: Settings (Cmd+,), Quit (Cmd+Q).  
  <span lang="zh-CN">**Koala**：设置（Cmd+,）、退出（Cmd+Q）。</span>

The whole app can also be played from the computer keyboard. [Read more](../8-settings#85-qwerty-keyboard-shortcuts) about the QWERTY layout and how to change it.  
<span lang="zh-CN">也可以用电脑键盘演奏和操作整个应用。[查看 QWERTY 布局和修改方法](../8-settings#85-qwerty-keyboard-shortcuts)。</span>

Mouse tips: scroll to move around the piano roll, hold Shift while scrolling to move left and right, hold Alt to zoom in time and Alt+Shift to zoom vertically. Scroll the mouse wheel directly over the key column to zoom vertically or the timeline bar to zoom horizontally. Cmd/Ctrl+A selects all notes, and the view follows notes when you nudge them with the arrow keys. Cmd/Ctrl+click a knob to type an exact value. Fine-tune knobs by dragging slowly left and right.  
<span lang="zh-CN">鼠标技巧：滚动可在钢琴卷帘中移动，按住 Shift 滚动可左右移动。按住 Alt 可缩放时间轴，按住 Alt+Shift 可垂直缩放。也可直接在琴键栏或时间轴栏上滚动，分别进行垂直或水平缩放。用 Cmd+A 或 Ctrl+A 可全选音符，用方向键微移音符时视图会跟随。按住 Cmd 或 Ctrl 点击旋钮可输入精确数值。缓慢左右拖动旋钮可微调。</span>
