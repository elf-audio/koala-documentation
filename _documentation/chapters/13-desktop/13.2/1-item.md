* **File**: New Song (Cmd+N), Import Audio File (Cmd+J), Save Song (Cmd+S), Export Selected Samples (Shift+Cmd+R), Export All Samples, Export Current Sequence, Export All Sequences, Export Koala Song (Shift+Cmd+E), Open Song Folder, Take screenshot (Cmd+P).
* **Edit**: Undo (Cmd+Z), Redo (Shift+Cmd+Z), Label Current Pad (Cmd+L), Sample Info (Cmd+I), Edit Sample (Cmd+E) which opens the wave editor.
* **Window**: resize the window to common phone and tablet sizes, or flip between Landscape and Portrait (Cmd+9). Koala's layout adapts to the window just like it does to different screens.
* **Help**: Keyboard shortcuts, About Koala.
* **Koala**: Settings (Cmd+,), Quit (Cmd+Q).

The whole app can also be played from the computer keyboard. [Read more](../8-settings#85-qwerty-keyboard-shortcuts) about the QWERTY layout and how to change it.

Mouse tips: scroll to move around the piano roll, hold Shift while scrolling to move left and right, hold Alt to zoom in time and Alt+Shift to zoom vertically. Cmd+click a knob to type an exact value. Fine-tune knobs by dragging slowly left and right.
