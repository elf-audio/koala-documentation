CURRENT SEQUENCE and ALL SEQUENCES can be exported MIXED, as STEMS or, with the MIXER add-on, as BUSES. MIXED is one stereo file with the whole sequence mixed down. STEMS is one file per pad in the length of the sequence. BUSES is one file per mixer bus, so you can continue mixing in your DAW with Koala's bus effects baked in.  
<span lang="zh-CN">CURRENT SEQUENCE（当前音序）和 ALL SEQUENCES（全部音序）均可导出为 MIXED（混缩）或 STEMS（分轨）。解锁 MIXER（混音器）后还可选 BUSES（按总线）。MIXED 将整条音序混缩到一个立体声文件。STEMS 为每个打击垫输出一个与音序等长的文件。BUSES 为每条混音总线输出一个文件，并将 Koala 的总线效果写入音频，方便在 DAW 中继续混音。</span>
