<h2 id="111-auv3-instrument-no-input-captured">11.1. AUv3 Instrument (no input captured)<br><span lang="zh-CN">11.1. AUv3 乐器（无音频输入采集）</span></h2>

{% flexible_image link="auv3-instrument.png" alt="AUv3 instrument mode" %}

Koala can be loaded as an AUv3 instrument into any AUv3 compatible host application. This makes Koala the signal source.  
<span lang="zh-CN">在任何兼容 AUv3 的宿主应用中，都可以把 Koala 加载为 AUv3 乐器，此时 Koala 作为音源。</span>

Note: Koala cannot capture audio thru it’s INPUT setting in this mode.  
<span lang="zh-CN">注意：在此模式下，Koala 无法通过 INPUT（输入）采集音频。</span>
