**Use MIDI mapping:** enables the MIDI learn functionality. Turn this on and a button Map MIDI will appear below this option which enters the MIDI mapping mode.  
<span lang="zh-CN">**Use MIDI mapping（使用 MIDI 映射）**：启用 MIDI 学习。开启后，下方会出现 Map MIDI 按钮，点击即可进入映射模式。</span>

In mapping mode, tap any control on the screen, then press the key or move the knob on your controller you want to use for it. The control is highlighted in the colour of the mapping scope. Tap DONE when finished. Pads, sliders, toggles, menu items, the sequence slots and perform effects can all be mapped, as can play, record, tempo, swing, quantize, undo and redo.  
<span lang="zh-CN">在映射模式下，点选屏幕控件，再按控制器上要分配的键，或转动对应旋钮。控件会以其映射范围对应的颜色高亮。完成后点击 DONE。可映射打击垫、滑杆、开关、菜单项、音序槽位、演奏效果，以及播放、录音、速度、摇摆、量化、撤销和重做。</span>

**Pickup:** mapped knobs only take effect once they move past the parameter's current value, preventing sudden jumps when a knob and the on-screen control disagree.  
<span lang="zh-CN">**Pickup（拾取）**：映射的旋钮越过参数当前值后才生效，可避免实体旋钮位置与屏幕数值不一致时发生突变。</span>

**Synth pads and bus effects (saved per song):** Quokka parameters, plugin parameters and mixer bus effects can all be MIDI-mapped. Mappings for synth pads and bus effects are saved with the song. Global pads, transport and UI controls stay in your global MIDI map.  
<span lang="zh-CN">**合成器打击垫与总线效果（按工程保存）**：Quokka、插件参数和混音器总线效果均可映射。合成器打击垫与总线效果的映射随工程保存。全局打击垫、播放录音和界面控件仍保存在全局 MIDI 映射中。</span>

**Quick toggle & undo/redo:** toggle MIDI map mode from a computer keyboard (default key ";") or from a mapped MIDI button. You can undo and redo MIDI mapping changes.  
<span lang="zh-CN">**快速切换和撤销／重做**：可以用电脑键盘（默认键为 ;）或已映射的 MIDI 按钮切换映射模式，也可撤销或重做映射改动。</span>

**MIDI Map Editor:** tap the MIDI map editor button in MIDI settings to view, edit or remove individual mappings.  
<span lang="zh-CN">**MIDI Map Editor（MIDI 映射编辑器）**：点击 MIDI 设置中的编辑器按钮，可查看、编辑或移除单项映射。</span>

**Relative MIDI encoders:** MIDI learn automatically detects relative CC and NRPN increment/decrement encoders with speed-based acceleration. Mapped sample start/length encoders follow the current waveform zoom.  
<span lang="zh-CN">**相对式 MIDI 编码器**：MIDI 学习可自动识别相对 CC 和 NRPN 的增减式编码器，并按转动速度加速调节。用于调整采样起点和长度的编码器会跟随当前波形缩放级别。</span>

Global MIDI maps are saved with Koala's settings. Use the MIDI Map IMPORT and EXPORT buttons in the EXTRAS settings to move a map to another device.  
<span lang="zh-CN">全局 MIDI 映射随 Koala 设置保存。用 EXTRAS（其他）设置中的 MIDI Map IMPORT 和 EXPORT 按钮可在设备间迁移映射。</span>
