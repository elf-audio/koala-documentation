## 8.3. MIDI Settings
Important note: To trigger pads, MIDI note messages must be used. MIDI CC messages can be used to control many other controls of Koala, but not the pads.

A MIDI DEVICES panel at the bottom of the page lists connected inputs and outputs and shows the last note and CC received, which is useful for checking that your controller is talking to Koala.
