* **Show EQ** [SAMURAI]: Enable and disable EQ in the MIX tab of sample editor. [Read more](../4-sample#48-mix-and-eq) about using EQ.
* **Show Mute/Solo:** Enable and disable Mute and Solo buttons in the SAMPLE and SEQUENCE screen. [Read more](../4-sample#412-mute-and-solo) about mute/solo.
* **Show status bar** (iOS): show the system status bar with time and battery at the top of the screen.
* **Show file names on pads:** File names are automatically added as pad labels when this setting is on.
* **Show Debug Info:** adds an overlay with start, end, length and samples per pixel information on sample waveform editor.
* **Hide Apple Audio Units** (iOS, macOS): hides the built-in Apple Audio Units from the plugin browser.
* **Advanced Quantization Options:** adds a quantization menu to the TEMPO menu with the quantize division and LIVE QUANTIZE. [Read more](../5-sequence#53-tempo-menu).
* **Export bit depth:** switch between 16 bit and 24 bit for exported WAV files.
* **Koala Version:** information on the version number you're currently using and in-app purchases that are currently active. Tap the version number to see the exact build. Press and hold the OK button of the settings window for five seconds to switch debug logging on or off. A **Share log** button then appears, so you can send the log file to the developers when reporting a problem.
* **GET SAMURAI / Restore purchases** (iOS, Android): buy the add-ons or restore purchases you already own on a new device.
* **Stem splitter files:** tap UNINSTALL to remove the neural networks downloaded for the SPLIT STEMS feature. They are downloaded again the next time you need them.
* **Sample Packs:** shows how much space downloaded sample packs use. Tap UNINSTALL to remove them. You can always download them again without buying them again.
* **Save as template:** saves the current song as the template that NEW starts from. REMOVE TEMPLATE goes back to the standard empty song.
* **MIDI Map:** IMPORT and EXPORT your MIDI mapping as a .json file.
* **QWERTY Map:** EDIT the computer keyboard shortcuts, or IMPORT and EXPORT them. [Read more](#85-qwerty-keyboard-shortcuts).
* **Export Settings:** export all of Koala's settings as a file for backup or to copy them to another device.
* **Song folder** (desktop): shows where Koala keeps your songs and samples on disk.
