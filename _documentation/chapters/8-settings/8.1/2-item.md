* **One-shot enabled by default:** samples play to the end by default when on.
* **Hold to record:** hold the pad to record when on. Tap once to engage recording, tap again to stop recording when off.
* **Count in:** NONE, 1 BAR or 2 BARS counted in with the metronome before recording a sequence starts.
* **Pitch knob snap to semitone:** change the pitch in full semitones when on, change in cents when off.
* **Use waveform handles:** when on, you must touch the start or end marker directly to trim a sample, and one finger anywhere else pans the waveform. When off, touching anywhere grabs the nearest marker.
* **Enable auv3 state saving** (iOS AUv3 only): embeds your Koala session into the host's project file so it comes back when you reopen the project. Recommended.
* **Import Audio:** which file picker opens when you press IMPORT AUDIO or set the input source to IMPORT FILE and tap a pad: KOALA's own browser, the SYSTEM picker, or AUDIOSHARE on iOS when the AudioShare app is installed.
* **Warn before delete samples and sequences:** a short prompt to confirm deletion of the sample or clearing of the sequence. WARNING: this does not apply when dragging samples and sequences to the trash area.
* **Koala folder** (Android): opens the folder with your songs, samples and settings in the Files app so you can back them up. The same folder shows up as "Koala" in other apps' file pickers.
