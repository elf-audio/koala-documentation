| Key | Action |
|---|---|
| 1 2 3 4 / Q W E R / A S D F / Z X C V | Pads 1 to 16 of the current bank |
| Y U I O / H J K L | Sequence slots 1 to 8 |
| Space | Play / stop |
| 0 | Record on / off |
| M | Metronome on / off |
| / | Keyboard mode on / off |
| Shift (hold) | EDIT (multi-select pads) |
| N (hold) | SOLO |
| B (hold) | MUTE |
| [ and ] | Previous / next sample bank |
| { and } | Previous / next sequence bank |
| = and - | Add / remove a bar from the sequence |
| _ | DOUBLE UP the sequence |
| Tab / Shift+Tab | Next / previous screen |
| Left / Right arrows | Previous / next pad grid page |
| Down arrow | Open the SAMPLES browser |
| Delete | Delete the selection |

In keyboard mode the computer keyboard becomes a piano: A S D F G H J K L ; ' are the white keys from C upwards and W E T Y U O P the black keys, like musical typing in a DAW. Z and X shift the octave down and up.

Note: while in keyboard mode, the sequence keys are disabled so a wrong key does not change the pattern. On desktop, see the Edit and File menus for more shortcuts like undo, redo, save and export. [Read more](../13-desktop#132-menu-bar-and-shortcuts).
