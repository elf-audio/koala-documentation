### FILTER<br><span lang="zh-CN">滤波器</span>
Filter featuring multiple filter types and modulation options.  
<span lang="zh-CN">提供多种滤波器类型和调制选项。</span>

* FILTER TYPE: Lo-pass, Hi-pass, Talkbox, Wah Wah  
  <span lang="zh-CN">FILTER TYPE（滤波器类型）：低通、高通、话盒或哇音。</span>
* CUTOFF: 0.00–100%  
  <span lang="zh-CN">CUTOFF（截止频率）：0.00–100%。</span>
* RESONANCE: 1.0–10.0  
  <span lang="zh-CN">RESONANCE（共振）：1.0–10.0。</span>
* ENV: envelope follower, lets the input level move the cutoff for auto-wah and dynamic filter effects  
  <span lang="zh-CN">ENV（包络跟随器）：让输入电平控制截止频率，可产生自动哇音和动态滤波效果。</span>
* ENV DEPTH: -100–100%, negative values close the filter on loud input  
  <span lang="zh-CN">ENV DEPTH（包络深度）：−100 至 +100%，负值会在输入声较响时关小滤波器。</span>
* ENV ATTACK: 1–120 ms  
  <span lang="zh-CN">ENV ATTACK（包络起音）：1–120 ms。</span>
* ENV RELEASE: 50–400 ms  
  <span lang="zh-CN">ENV RELEASE（包络释音）：50–400 ms。</span>
* LFO: red dot pulsates in set speed and depth  
  <span lang="zh-CN">LFO（低频振荡器）：红点会按设定的速度和深度变化。</span>
* DEPTH: 0.00–100%  
  <span lang="zh-CN">DEPTH（深度）：0.00–100%。</span>
* SPEED: 0.000000–30 Hz / 1/64–8 bars  
  <span lang="zh-CN">SPEED（速度）：0.000000–30 Hz / 1/64–8 小节。</span>
* WAVEFORM: Sinus, Square, Triangle, Saw, Inverted Saw, Random Square, Random Triangle  
  <span lang="zh-CN">WAVEFORM（波形）：正弦波、方波、三角波、锯齿波、反向锯齿波、随机方波、随机三角波。</span>
* TEMPO SYNC: on/off  
  <span lang="zh-CN">TEMPO SYNC（速度同步）：开启／关闭。</span>
