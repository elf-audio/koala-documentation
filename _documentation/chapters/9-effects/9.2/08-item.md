### FILTER
Filter featuring multiple filter types and modulation options.

* FILTER TYPE: Lo-pass, Hi-pass, Talkbox, Wah Wah
* CUTOFF: 0.00–100%
* RESONANCE: 1.0–10.0
* ENV: envelope follower, lets the input level move the cutoff for auto-wah and dynamic filter effects
* ENV DEPTH: -100–100%, negative values close the filter on loud input
* ENV ATTACK: 1–120 ms
* ENV RELEASE: 50–400 ms
* LFO: red dot pulsates in set speed and depth
* DEPTH: 0.00–100%
* SPEED: 0.000000–30 Hz / 1/64–8 bars
* WAVEFORM: Sinus, Square, Triangle, Saw, Inverted Saw, Random Square, Random Triangle
* TEMPO SYNC: on/off
