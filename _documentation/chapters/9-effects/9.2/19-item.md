### RING MOD<br><span lang="zh-CN">环形调制</span>
Ring modulator.  
<span lang="zh-CN">环形调制效果。</span>

* FREQ: 1.0 Hz to 8.00 kHz  
  <span lang="zh-CN">FREQ（频率）：1.0 Hz 至 8.00 kHz。</span>
* MIX: 0.0–100%  
  <span lang="zh-CN">MIX（混合量）：0.0–100%。</span>
* DRIVE: 0.0–18.0 dB  
  <span lang="zh-CN">DRIVE（驱动）：0.0–18.0 dB。</span>
* LFO: red dot pulsates in set speed and depth  
  <span lang="zh-CN">LFO（低频振荡器）：红点会按设定的速度和深度变化。</span>
* DEPTH: 0.0–100%  
  <span lang="zh-CN">DEPTH（深度）：0.0–100%。</span>
* SPEED: 0.000000–30 Hz / 1/64–8 bars  
  <span lang="zh-CN">SPEED（速度）：0.000000–30 Hz / 1/64–8 小节。</span>
* STEREO: 0.00–100%  
  <span lang="zh-CN">STEREO（立体声）：0.00–100%。</span>
* WAVEFORM: Sinus, Square, Triangle, Saw, Inverted Saw, Random Square, Random Triangle  
  <span lang="zh-CN">WAVEFORM（波形）：正弦波、方波、三角波、锯齿波、反向锯齿波、随机方波、随机三角波。</span>
* TEMPO SYNC: on/off  
  <span lang="zh-CN">TEMPO SYNC（速度同步）：开启／关闭。</span>
