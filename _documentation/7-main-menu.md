Last screen is the MENU screen. Options to create, load, save, export, import and adjust settings are all accessed through the MENU.  
<span lang="zh-CN">主菜单（MENU）集中提供新建、载入、保存、导出、导入和设置等选项。</span>

Tap MENU to see the current name and size of your song. Information on available storage and RAM is shown below. Tap the cog next to the song name for song options. [Read more](#713-song-options).  
<span lang="zh-CN">点击 MENU 可查看当前工程的名称和大小，下方会显示可用存储空间和运行内存。点击工程名称旁的齿轮，可打开工程选项。[了解更多](#713-song-options)。</span>

Note: the number of songs you can save is only limited by the available space on your device.  
<span lang="zh-CN">注意：设备的可用存储空间决定了你能保存多少个工程。</span>
